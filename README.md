## 🎫 Tentang Tixify

**Tixify** adalah dashboard admin untuk mengelola penjualan tiket konser secara real-time. Dibangun sebagai proyek sekolah menggunakan **Next.js (App Router)**, **Tailwind CSS**, **Recharts**, dan **Lucide Icons**, Tixify memudahkan admin memantau penjualan, pengguna, dan jadwal konser dalam satu tempat yang rapi dan modern.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 👥 **Users** | Kelola data pengguna terdaftar |
| 💰 **Penjualan** | Pantau statistik dan laporan penjualan tiket |
| 🎟️ **Ticket Concert** | Manajemen tiket per event konser |
| 🎤 **Concert Management** | Tambah, edit, dan hapus data konser |
| 📊 **Dashboard Analitik** | Visualisasi data dengan grafik interaktif (Recharts) |
| 📱 **Responsive Sidebar Layout** | Navigasi konsisten di seluruh halaman |

## 🚀 Instalasi & Menjalankan Project

```bash
# Clone repository
git clone https://github.com/username/tixify.git

# Masuk ke folder project
cd tixify

# Install dependencies
npm install

# Jalankan development server
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.
